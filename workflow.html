两种运行模式

🔷 守护进程模式 (推荐)

多个客户端共享单一 J-Link 连接

  • 启动 http_server.py 守护进程
  • Claude Code 通过 bridge.py 代理到 daemon
  • VSCode 扩展也连接同一 daemon
  • 零争用，共享连接

命令: rtt-mcp-daemon --host 127.0.0.1 --port 8765

🔶 独立模式 (fallback)

daemon 未运行时自动启用

  • server.py 检测 daemon 不可达
  • 直接打开 J-Link 连接
  • 适用于 Claude-only 会话
  • 与 VSCode 扩展不共存

自动检测，无需手动切换
